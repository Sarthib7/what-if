What-IF · Add to your AI

Use What-IF in Claude or ChatGPT

What-IF works inside the AI app you already use. You add it once, a bit like saving a contact: about 2 minutes, no programming. Then you just ask “What if…?”.

No AI app?

Answer a few questions on this site instead. You get the same report, worked out in your browser.

Try it with your numbers →

1. Your invite code

What-IF is a closed beta for Berlin cafés. Your code goes into your personal link, so only you need it.

2. Your personal link

Your personal What-IF link {{SITE_URL}}/api/mcp

3. Add it to your AI app

Easiest: Claude claude.ai in your browser, or the Claude app on your computer

  1. Open Claude and go to Settings → Connectors.
  2. Click Add custom connector.
  3. Name it What-IF, paste your personal link and click Add: {{SITE_URL}}/api/mcp
  4. Start a new chat, switch What-IF on in the tools menu, and write “What if…?” in your own words.

About 2 minutes. You only do this once.

ChatGPT

ChatGPT only accepts your own connectors in “Developer mode”. The name sounds technical, but it is a normal setting: no programming.

  1. Open Settings → Apps & Connectors → Advanced settings and turn on Developer mode.
  2. Back in Apps & Connectors, click Create.
  3. Name it What-IF, paste your personal link as the server URL, and choose No authentication.
  4. In a chat, pick What-IF from the + menu and write “What if…?”.

Then just ask

Write the way you would to a friend, for example “What if I offer a weekday lunch deal for €9.90?”. What-IF asks for a few numbers, one at a time, and sends you a report link after each step.

For developers: Claude Code, Cursor, VS Code and other MCP clients

Claude Code

Claude Code — run this once in your terminal:

claude mcp add --transport http what-if "{{SITE_URL}}/api/mcp"

Then type /mcp to check it is connected.

Cursor · VS Code · Windsurf

Cursor, VS Code, Windsurf — add What-IF to your mcp.json:

Cursor — ~/.cursor/mcp.json

{
  "mcpServers": {
    "what-if": { "url": "{{SITE_URL}}/api/mcp" }
  }
}

VS Code — .vscode/mcp.json

{
  "servers": {
    "what-if": { "type": "http", "url": "{{SITE_URL}}/api/mcp" }
  }
}

Windsurf uses the same block in ~/.codeium/windsurf/mcp_config.json, with "serverUrl" in place of "url".

Any other MCP client

What-IF is a remote MCP server (Streamable HTTP, stateless). Use your personal link; the invite code can also go in an x-whatif-code header or as Authorization: Bearer <code>. Nothing is kept on the server: your numbers travel in the request and in the report link.

Optional: the skill

Teach Claude the What-IF method

The skill tells Claude when to start (any “what if…” about your café), how to coach one question at a time, and how to run the rehearsal. It works best together with the connector.

Download what-if-skill.zip

Claude.ai

  1. Open Settings → Capabilities → Skills.
  2. Choose Upload skill and pick what-if-skill.zip.
  3. Ask “What if…?” in any chat.

Claude Code

Unzip it into your skills folder, so you get ~/.claude/skills/what-if/SKILL.md:

unzip what-if-skill.zip -d ~/.claude/skills/

Possibilities, not promises. What-IF shows what could happen and why. It does not predict the future, and it does not replace your Steuerberater or other professional advice.
