Two pieces, both free: the connector (an MCP server that does the maths, the rehearsal and the report) and the skill (which teaches Claude the coaching method). Add the connector first; the skill is optional.

Add What-IF to your AI

The connector: one link for every app

What-IF is an MCP server: a connector your AI app can call for the maths, the rehearsal and the report. No sign-in, and it stores nothing.

Your What-IF connector URL {{SITE_URL}}/api/mcp

Claude claude.ai and Claude Desktop

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it What-IF and paste the URL above. Click Add.
  4. In a chat, switch What-IF on in the tools menu, then ask “What if…?”

Claude Code

Run this once in your terminal:

claude mcp add --transport http what-if {{SITE_URL}}/api/mcp

Then type /mcp to check it is connected, and ask “What if…?”

ChatGPT

  1. Open Settings → Apps & Connectors → Advanced and turn on Developer mode.
  2. Back in Apps & Connectors, choose Create.
  3. Name it What-IF, paste the URL above as the MCP server URL, and choose no authentication.
  4. In a chat, pick What-IF from the + menu and ask “What if…?”

Cursor, VS Code, Windsurf

Add What-IF to your mcp.json:

Cursor — ~/.cursor/mcp.json

{
  "mcpServers": {
    "what-if": { "url": "{{SITE_URL}}/api/mcp" }
  }
}

VS Code — .vscode/mcp.json

{
  "servers": {
    "what-if": { "type": "http", "url": "{{SITE_URL}}/api/mcp" }
  }
}

Windsurf uses the same block in ~/.codeium/windsurf/mcp_config.json, with "serverUrl" in place of "url".

Any other MCP client

Add a remote server with the Streamable HTTP transport and the URL above. There is no sign-in and no API key. Every tool is stateless: your numbers travel in the request and in the report link, and nothing is kept on the server.

Get the skill

Teach your AI the What-IF method

The skill tells Claude when to start (any “what if…” about your business), how to coach one question at a time, and how to run the rehearsal. It works best with the connector above.

Download what-if-skill.zip

Claude.ai

  1. Open Settings → Capabilities → Skills.
  2. Choose Upload skill and pick what-if-skill.zip.
  3. Ask “What if…?” in any chat.

Claude Code

Unzip it into your skills folder, so you get ~/.claude/skills/what-if/SKILL.md:

unzip what-if-skill.zip -d ~/.claude/skills/

Possibilities, not promises. What-IF shows what could happen and why. It does not predict the future, and it is not a substitute for an accountant or other professional advice.
