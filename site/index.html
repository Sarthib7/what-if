The method

Seven small steps from “what if” to “let's try it”

The same steps a good adviser would walk you through. What-IF shows each one, so you learn the method, not just the answer.

  1. 1

    Ask

    Say it the way you would to a friend: “What if I run a weekday lunch offer?” What-IF turns it into one decision, compared with carrying on as now.

    What if I run a weekday lunch offer?
  2. 2

    Your numbers

    A few figures from your till and your costs, plus the guesses nobody knows yet. Each one is labelled, so you always see what came from you and what is a guess.

    • Customers a day140Your number
    • Extra at lunch8A guess
    • Takings a day€1,036Calculated
  3. 3

    Possible outcomes

    Three versions of the future — a slow start, your likely guess and a strong one — worked out with plain arithmetic you can open and check.

  4. 4

    Break-even

    The one number to remember: how many extra customers you need before the change pays. Move a slider and watch the result — and the explanation — change.

  5. 5

    Rehearse with imagined customers

    A student, an office worker, a regular… imagined customers react over a few rounds. They are not data: they help you find the questions to ask real people.

    MJAH
    Imagined
  6. 6

    Small test

    Two weeks, a cost cap, one thing to count, and a rule agreed before you start: keep, tweak or stop. Printable, so it can live by the till.

    10-day testKeepTweakStop
  7. 7

    Learn

    Tell the coach what happened. What-IF puts reality next to your three guesses, so next time your guesses are better — and you can use the method without it.

How the rehearsal works

A dress rehearsal with imagined customers

Inspired by swarm simulations like MiroFish, made small and honest for one café: a handful of imagined people, a few rounds, no hidden services.

  1. MJAHSL

    1 Imagined customers

    Six made-up people, each with a routine, a lunch budget, a mood about your café and a memory of it.

  2. 2 Rounds

    Each round, everyone who is around picks one thing to do: try it, tell a friend, ignore it, or nothing at all.

  3. Mia told Jonas: “the soup deal is good value”

    You added rain all week

    3 Neighbourhood feed

    What they say spreads to the others next round. You can add an event — rain, a rival's offer — and see what changes.

    • Is there a vegan soup?
    • Does €9.90 include coffee?
    • 3 of 6 tried it

    4 Summary

    Questions to ask real customers, and plain counts like “3 of 6 imagined customers tried it” — never scaled up.

Honest by design

Imagined customers are not data. A rehearsal can show you questions, doubts and wording problems before you spend money. It cannot tell you how many real people will come, and it never feeds the maths. The small test with real customers does that.

Add What-IF to your AI

One link works in Claude, ChatGPT, Cursor and more

What-IF is an MCP server: a connector your AI app can call for the maths, the rehearsal and the report. No sign-in, and it stores nothing.

Your What-IF connector URL {{SITE_URL}}/api/mcp

Claude claude.ai and Claude Desktop

  1. Open Settings → Connectors.
  2. Choose Add custom connector.
  3. Name it What-IF and paste the URL above. Click Add.
  4. In a chat, switch What-IF on in the tools menu, then ask “What if…?”

Claude Code

Run this once in your terminal:

claude mcp add --transport http what-if {{SITE_URL}}/api/mcp

Then type /mcp to check it is connected, and ask “What if…?”

ChatGPT

  1. Open Settings → Apps & Connectors → Advanced and turn on Developer mode.
  2. Back in Apps & Connectors, choose Create.
  3. Name it What-IF, paste the URL above as the MCP server URL, and choose no authentication.
  4. In a chat, pick What-IF from the + menu and ask “What if…?”

Cursor, VS Code, Windsurf

Add What-IF to your mcp.json:

Cursor — ~/.cursor/mcp.json

{
  "mcpServers": {
    "what-if": { "url": "{{SITE_URL}}/api/mcp" }
  }
}

VS Code — .vscode/mcp.json

{
  "servers": {
    "what-if": { "type": "http", "url": "{{SITE_URL}}/api/mcp" }
  }
}

Windsurf uses the same block in ~/.codeium/windsurf/mcp_config.json, with "serverUrl" in place of "url".

Any other MCP client

Add a remote server with the Streamable HTTP transport and the URL above. There is no sign-in and no API key. Every tool is stateless: your numbers travel in the request and in the report link, and nothing is kept on the server.

Get the skill

Teach your AI the What-IF method

The skill tells Claude when to start (any “what if…” about your business), how to coach one question at a time, and how to run the rehearsal. It works best with the connector above.

Download what-if-skill.zip

Claude.ai

  1. Open Settings → Capabilities → Skills.
  2. Choose Upload skill and pick what-if-skill.zip.
  3. Ask “What if…?” in any chat.

Claude Code

Unzip it into your skills folder, so you get ~/.claude/skills/what-if/SKILL.md:

unzip what-if-skill.zip -d ~/.claude/skills/

Then just say “what if…”

Three ways to start

  • What if I run a weekday lunch offer at €9.90?

    What-IF asks for a few numbers, one at a time, then shows three outcomes and your break-even.

  • What if I put my flat white up from €3.90 to €4.20?

    You see how many sales you could lose before you are worse off, and how to test it for two weeks.

  • What if I try a lunch deal? Rehearse it with imagined customers first.

    Imagined customers react over four rounds; you get the questions to ask real ones this week.

Possibilities, not promises. What-IF shows what could happen and why. It does not predict the future, and it is not a substitute for an accountant or other professional advice.
